Cifrado César

Cada letra se desplaza un número fijo de posiciones en el alfabeto.

III
Texto cifrado
¿Cómo se calcula cada letra?

Para cada letra del texto se toma su posición en el alfabeto (a = 0, b = 1, …), se le suma la llave k, y el resultado se ajusta con % 26 para que el conteo vuelva a empezar si se pasa de z. Al descifrar se aplica el mismo cálculo pero con k en negativo, deshaciendo el desplazamiento. Los espacios, números y signos de puntuación no se modifican.
